# FIOFI LiveClipper — esploratore 3D

Modello 3D navigabile della console di replay FIOFI LiveClipper: scocca,
comandi, elettronica e quote, pezzo per pezzo.

Pagina: `index.html` (l'esploratore sta sotto l'ancora `#/esplora`).

Questa cartella contiene **solo il sito gia' compilato**. I sorgenti
stanno nel progetto, e si ripubblica con `statico/pubblica.sh`.
